# Spring Boot + React Authentication System

## Tech Stack
- Java 21, Spring Boot
- Oracle XE
- React (Vite)
- Axios
- Git & GitHub

## Features
- User Registration
- Login with password expiry
- Forgot password with security questions
- Change password
- Clean REST APIs
- React frontend with routing

## How to Run
### Backend
cd user-authentication-system
./mvnw spring-boot:run

### Frontend
cd auth-frontend
npm install
npm run dev
